# TechZone
> La empresa TechZone es un negocio dedicado a la venta de productos tecnológicos, desde laptops y teléfonos hasta accesorios y componentes electrónicos. 

## Descripción General
Este proyecto es la solución al modelo de datos de la empresa TechZone que busca la expansion de su empresa.

`Para mas detalles ir a: requirements/requirements.md`

## Instrucciones para la base de  datos.
-  Primero importar la base de datos script/ddl/db.sql
- Insertar los datos script/dqml/insert.sql
- Insertar el procedimiento almacenado script/dml/procedures.sql
- Hacer las respectivas consultas dql/queries.sql

*Todo se ejecuta desde la terminal*
